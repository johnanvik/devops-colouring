# Definition of Done
A product is considered completed if the following are true:

## Single Product
1. The drawing is coloured.
1. The drawing is labelled as `Ready` in the product request.

## Deployment Package
1. The number of products for the product request is the same as the batch size.
1. All drawings are from the same URL.
    - Check that a developer did not attach the wrong file.
1. The product request is:
    - Labelled with the team's number (e.g. "Team 1").
    - Labelled with the sprint number (e.g. "Sprint 2").
